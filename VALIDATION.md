# Firmware compatibility validation

The same reviewed path manifest covers A67L Gen 2 firmware 1784605054 and
1790133188. Module IDs are unchanged. Version v0.4 / versionCode 4 contains the
firmware-compatibility changes.

## Automated checks

`python tests/test_module.py` runs the production installer and cleanup shell
against isolated old/new firmware layouts, with fake package-manager responses
and whiteout creation. It exercises saved-choice upgrades, v0.3 whiteout
inference, defaults and explicit selections, stale legacy flags, absent targets
covered for future OTA, current target paths, backup failure, split APK backup,
changed identity, stock APKs still visible, unknown signers, verified key
rotation, rejection of multi-signer subsets, failed removal retry and retained
backups. Degoogler also exercises cancellation, A/C optional groups, B additions,
launcher preservation and upgrades with microG already installed.

The fixtures do not perform real Android mounting, package removal, microG
setup, or firmware installation. Five Degoogler-only cases are skipped in the
Debloat copy of the common suite.

Shell syntax and patch whitespace checks pass. The builder compiles the helper
against Android APIs and packages only declared runtime/documentation files;
source, tests and device evidence are excluded from the install ZIP. Toolchain
paths are configurable in build.py. Fixed ZIP metadata makes repeated builds
with the same toolchain byte-identical.

## Firmware and device evidence

Every existing removal path remains present in both extracted stock images.
The extra RuntimeTest overlay, ASI app/overlay/feature declaration and Auto stub
are present only in the newer image; Private Compute Services is present in
both. Public signer pins were generated by successful apksigner verification
of target APKs from both images, selecting the SDK-appropriate APK signer rather
than the separate source-stamp certificate. Google key rotation is accepted
only through the actual APK's Android-verified signing history.

The read-only PackageProbe helper was run against ASI, Private Compute Services,
Auto, updated Play services and Search Go on 1790133188. All were recognized by
actual APK signer or verified history; removed RuntimeTest was reported absent.

## Installation and boot testing — 2026-11-17

Both v0.4 modules were installed using the real KernelSU Next 3.4.0 / NoMount
installer, with the published runtime payload and real volume-key input.
A legacy installer-name conflict found during testing was fixed by naming the
sourced configuration script `configure.sh`; a packaging regression test covers
that KernelSU protocol requirement. The 49 applicable host cases pass (22 for
Debloat, 27 for Degoogler; five Google-only cases are skipped in Debloat).

- Debloat preserved all 17 v0.3 choices and added the RuntimeTest overlay.
  All selected apps and both companion overlays were absent after reboot;
  Face Unlock stayed off and LinkTurbo's daemon stayed stopped.
- Degoogler was tested in **A with optional intelligence and Auto removal**.
  All six selected packages, ASI's configuration overlay and feature declaration
  were hidden. Its actual updated Private Compute Services copy was removed
  after backup; cleanup completed with no pending failures. Six complete app
  backups were retained and their compressed archives read successfully.
- ASI service configuration fell back to the framework's empty defaults.
  Settings, Home and Recents smoke checks passed, with real Google services,
  Play Store and Search Go retained. The post-boot crash buffer was empty.
- Disabling Degoogler and rebooting revealed all selected stock apps again.
  The later uninstall and normal reboot removed Degoogler completely, as
  requested. The original Private Compute Services split APK update was
  reinstalled, its APK hashes matched the retained backup, and available
  persistent app data and original stopped=false state were restored.
- Final phone state retains Debloat v0.4, no Degoogler and no pending module
  updates. Root, custom kernel/boot-image digest, successful slot B, SELinux
  Enforcing, idle firmware engine and Bluestone's active guard were retained.
  No firmware update or partition-writing tool was used for these tests.

## Boundaries

Older 1784605054 compatibility is based on its extracted stock target/signature
inventory and old/new layout fixtures; it was not flashed or boot-tested.
A later OTA introducing a previously absent path has not been exercised on
hardware. B's real Google-services removal, microG setup and launcher behavior
without Google Search were not tested on the phone. Their selection and
replacement-protection logic are covered by fixtures. No measured battery,
RAM-saving or universal third-party-app compatibility claim is made.
